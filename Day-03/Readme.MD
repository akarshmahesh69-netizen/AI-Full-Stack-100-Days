## Software Thinking

Pattern:

Problem → User → Need → Solution → Features → MVP → Test

Key idea:

Software thinking means understanding what problem we are solving and why before deciding what to build or what technology to use.

## Systems Thinking

Pattern:

User → Input → Processing → Data → Output → Failure

Key idea:

A software system is made of connected parts. We need to understand how information moves through the system and what happens when something fails.

## AI Fundamentals

Pattern:

User Input → AI Understands → Software Acts/Checks → AI/Application Responds

Key idea:

AI is one component of an application.

- AI → understands/generates
- Backend → business logic/actions
- Database → stores information

AI should not automatically make every business decision.

## Prompt Engineering

Pattern:

Context → Goal → Requirements → Constraints → Expected Output

For complex tasks:

Big Goal → Meaningful Tasks → Build → Check → Next Task

Key idea:

Prompt engineering is not about using magic words. It is about clearly expressing what we want, what matters, what must not change, and what the expected result should be.
